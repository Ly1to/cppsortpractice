# 随机测试数据生成器

项目提供 [`tools/generate_rides.py`](../tools/generate_rides.py)，用于生成与 `rides_1k.txt`、`rides_10k.txt` 和 `rides_50k_B.txt` 格式一致的随机骑行记录。生成器只依赖 Python 3 标准库。

## 数据格式

文件第一行是记录数，后续每行包含五个以空白分隔的字段：

```text
记录数
车辆编号 开始时间 骑行时长 费用 起点区域
```

例如：

```text
3
NB-1613 1330  18   2.09 A1
NB-1737 1333  13   2.03 A3
NB-2481 1131  21   2.32 B1
```

字段含义和取值范围如下：

| 字段 | 示例 | 生成范围 |
| --- | --- | --- |
| 车辆编号 | `NB-1613` | `NB-1001` 至 `NB-3000` |
| 开始时间 | `1330` | 当天第 `0` 至 `1439` 分钟 |
| 骑行时长 | `18` | 大多为 `5` 至 `45` 分钟，约 3% 为 `50` 至 `180` 分钟 |
| 费用 | `2.09` | 大多为 `1.15` 至 `4.50`，约 1% 为 `4.50` 至 `14.00` |
| 起点区域 | `A1` | `A1` 至 `A5`、`B1` 至 `B2`、`C1` |

生成器会近似模仿现有测试数据的分布，包括早晚高峰和不同区域的使用比例。它用于功能测试和耗时对比，不用于还原真实业务数据。

## 直接运行

生成默认的 10000 条记录：

```sh
python3 tools/generate_rides.py
```

默认输出到 `rides_10000_random.txt`。省略 `--seed` 时，程序会随机选择一个种子并打印出来。使用相同种子可以重新生成完全相同的文件。

指定记录数、种子和输出路径：

```sh
python3 tools/generate_rides.py \
  --count 100000 \
  --seed 2026 \
  --output /tmp/rides_100k.txt
```

也可以将数据直接写到标准输出：

```sh
python3 tools/generate_rides.py --count 1000 --seed 42 --output -
```

## 使用 Makefile

```sh
make generate
```

默认生成 `rides_generated.txt`，记录数为 `10000`，种子为 `42`。可以通过变量覆盖：

```sh
make generate \
  GENERATE_COUNT=50000 \
  GENERATE_SEED=2026 \
  GENERATED_RIDES=/tmp/rides_50k.txt
```

生成后可直接交给排序程序：

```sh
make run RIDES=/tmp/rides_50k.txt
```

或者直接运行：

```sh
./build/OrdCsltion /tmp/rides_50k.txt
```

## 可复现性

同一条命令配合相同种子会生成相同内容：

```sh
python3 tools/generate_rides.py --count 10000 --seed 42 -o /tmp/a.txt
python3 tools/generate_rides.py --count 10000 --seed 42 -o /tmp/b.txt
cmp /tmp/a.txt /tmp/b.txt
```

如果两次命令都没有指定种子，程序会分别打印实际使用的种子。记录该值后，即可用 `--seed` 重建同一次测试数据。
